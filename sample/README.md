# サンプルデータ（動作確認用）

このディレクトリには、`abuse_check.rb` のすべての判定ステータス（7種類）および主要機能を検証するためのサンプルデータが含まれています。

---

## 1. ファイル構成

| ファイル名 | 概要 |
| :--- | :--- |
| `target_ips.csv` | 判定テスト用の入力IPリスト（全ステータス網羅） |
| `whitelist.csv` | ホワイトリスト設定（単一IPおよびCIDR指定） |
| `abuse_check_result.csv` | 本サンプルを入力としてスクリプトを実行した際の期待出力結果 |

---

## 2. 含まれるステータスとテストIP一覧

| IPアドレス / 文字列 | 判定ステータス (`status`) | スコア (`abuse_score`) | 検証目的 / 判定条件 |
| :--- | :--- | :--- | :--- |
| `185.220.101.5` | **High Risk** | 80〜100 (例: 100) | 悪用スコア80%以上の高リスクIP（Tor Exit Node等） |
| `141.98.11.22` | **Suspicious** | 20〜79 (例: 24) | 悪用スコア20%〜79%の不審なIP |
| `141.98.11.11` | **Low Risk** | 1〜19 (例: 15) | 悪用スコア1%〜19%の低リスクIP |
| `8.8.8.8` | **Clean** | 0 | 悪意報告なし（正常IP、Google Public DNS） |
| `203.0.113.15` | **Whitelisted** | 0 | ホワイトリスト（単一IP）一致によるAPI照会スキップ |
| `198.51.100.88` | **Whitelisted** | 0 | ホワイトリスト（CIDR `198.51.100.0/24`）一致による照会スキップ |
| `192.168.1.50` | **Private IP** | 0 | プライベートIP（RFC 1918）の自動除外 |
| `127.0.0.1` | **Private IP** | 0 | ループバックアドレスの自動除外 |
| `invalid-ip-string` | **Invalid IP** | *(nil)* | IPアドレス形式エラー文字列の自動スキップ |

---

## 3. 動作確認手順

### パターンA: `sample/` ディレクトリ内で実行
```bash
cd sample
ruby ../abuse_check.rb
```
※ `sample/abuse_check_result.csv` が上書き更新されます。

### パターンB: プロジェクトルートにコピーして実行
```bash
cp sample/target_ips.csv .
cp sample/whitelist.csv .
ruby abuse_check.rb
```
※ プロジェクトルートの `abuse_check_result.csv` が出力されます。
