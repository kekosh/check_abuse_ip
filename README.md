# check_abuse_ip

AbuseIPDB API (v2) を活用して、IPアドレス一覧の悪意スコア（`abuseConfidenceScore`）を自動照会・判定し、危険度順に出力するRubyスクリプトです。

---

## 主な機能・特徴

* **必要最小限のシンプルな入出力**
  * 調査対象のIP一覧から「IPアドレス」「悪意スコア」「判定ステータス」の3項目に絞った結果を出力します。
* **危険度順ソート**
  * 判定結果は悪意スコアの降順（高リスクが先頭）でソートされるため、即座に対処・分析が可能です。
* **APIクォータ消費の節約**
  * **重複排除**: 同一IPの重複リクエストを自動で1回にまとめます。
  * **プライベートIPスキップ**: `10.0.0.0/8`, `192.168.0.0/16`, `127.0.0.1` などのローカル/ループバックIPはAPI照会を行いません。
  * **ホワイトリスト照会**: 自社固定IPやVPN等のCIDR範囲（`/24` 等）を事前定義してAPI照会をスキップできます。
* **安全なAPIキー管理**
  * 設定ファイル `config.yml` は `.gitignore` によりGit管理外となります。
  * 初回実行時にパーミッション `0600`（所有者のみ読み書き可能）でテンプレートが自動生成されます。
* **外部依存ゼロ**
  * Ruby標準ライブラリ（`csv`, `net/http`, `ipaddr`, `json`, `yaml`）のみで動作し、`bundle install` などの事前準備が不要です。

---

## 必要要件

* Ruby 3.0 以上（標準ライブラリのみ使用）
* [AbuseIPDB](https://www.abuseipdb.com/) のアカウントおよびAPIキー

---

## 利用方法

### 1. 初回実行（設定ファイルの生成）

スクリプトを実行します。

```bash
ruby abuse_check.rb
```

初回実行時は設定ファイルが存在しないため、テンプレート `config.yml` が自動作成（権限 `0600`）されて終了します。

```text
[INFO] 設定ファイルが見つからないため、テンプレートを作成しました: .../config.yml
[INFO] ファイルの 'api_key' に有効なAPIキーを設定し、再度実行してください。
```

### 2. APIキーの設定

自動生成された `config.yml` をエディタで開き、取得したAbuseIPDBのAPIキーを入力します。

```yaml
# config.yml
api_key: "YOUR_ABUSEIPDB_API_KEY_HERE"
```

### 3. 入力ファイルの準備

#### ① 調査対象IPリスト: `target_ips.csv` (必須)
調査したいIPアドレスを1列で記述します。

```csv
ip_address
185.220.101.5
118.25.6.39
203.0.113.15
192.168.1.50
```

#### ② 除外ホワイトリスト: `whitelist.csv` (任意)
API照会をスキップしたい自社IPやVPNのサブネット（CIDR）を指定します。

```csv
ip_or_cidr
203.0.113.15
198.51.100.0/24
```
*(※ `whitelist.csv` が存在しない場合は除外なしで全件照会されます)*

### 4. 判定スクリプトの実行

再度スクリプトを実行します。

```bash
ruby abuse_check.rb
```

**実行ログ例:**
```text
ホワイトリスト登録件数: 2 件
総行数: 4 行 / ユニークIP数: 4 件
  - ホワイトリスト除外: 1 件
  - プライベートIP除外: 1 件
  - 外部API照会対象: 2 件
照会中... (1/2): 118.25.6.39
照会中... (2/2): 185.220.101.5
照会完了。
結果を出力しました: abuse_check_result.csv
```

### 5. 判定結果の確認

出力された `abuse_check_result.csv` を確認します。高リスクなIPが上位にソートされて出力されます。

```csv
ip_address,abuse_score,status
185.220.101.5,100,High Risk
118.25.6.39,85,High Risk
203.0.113.15,0,Whitelisted
192.168.1.50,0,Private IP
```

---

## ステータス（`status`）一覧

| ステータス (`status`) | スコア範囲 (`abuse_score`) | 内容 |
| :--- | :--- | :--- |
| **`High Risk`** | 80% 〜 100% | 極めて危険（即時ブロック推奨） |
| **`Suspicious`** | 20% 〜 79% | 要警戒・不審なアクティビティあり |
| **`Low Risk`** | 1% 〜 19% | 低リスク（軽微な過去報告など） |
| **`Clean`** | 0% | 悪意報告なし（正常） |
| **`Whitelisted`** | 0% | ホワイトリストに合致（API消費なし） |
| **`Private IP`** | 0% | プライベート/ループバックIP（API消費なし） |
| **`Invalid IP`** | *(空欄)* | IPアドレス形式エラー（API消費なし） |
| **`API Error`** | *(空欄)* | 通信エラーまたはレートリミット到達 |
